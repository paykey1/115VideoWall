# 115 视频墙 1.0.0

这是一个用来同时在115看多个片的小工具/doge。对于带鱼屏和超大屏非常友好~你懂的
浏览器与视频墙使用独立的无边框窗口。每路播放使用 115 的网页播放器，和文件浏览页共享同一套内嵌浏览器登录状态。

## 软件功能

- 在一个或多个视频墙中同时观看 115 网盘视频，可拖动视频跨墙移动、自定义行列和全屏播放。
- 用内置浏览器查看 115 文件或其他网站，支持收藏栏、标签排序、后台打开标签和浏览历史。
- 将磁力与电驴文件链接交给独立后台页面提交到 115 云下载，前台标签保持原样。
- 支持 115 自动登录、本地窗口布局记忆和可自定义的全局老板键。

## 使用

1. 在 64 位 Windows 10 或 11 上运行 [115 视频墙 1.0.0 离线安装包](https://github.com/paykey1/115VideoWall/releases/download/v1.0.0/115VideoWall-Setup-1.0.0-x64.exe)。安装包内置 .NET 8 和 WebView2 浏览器运行时，安装无需联网。登录网盘、播放和提交云下载时需要网络。
2. 在 **115 浏览器** 窗口的 115 文件标签正常登录，像平时一样打开视频。视频会进入独立的 **115 视频墙** 窗口，并自动开启播放器自带的「网页全屏」、关闭右下角活动弹窗。文件窗口保留原位置和浏览状态。
3. 默认每面视频墙最多 6 路，满 6 路时按 3×2 排列，总路数上限为 12。按住视频顶部标题拖动，拖到另一面墙可移动视频，拖到墙外可在松手处新建视频墙。只有一路视频的墙也可以拖动窗口标题并入另一面墙。目标墙满时视频留在原处。在 115 打开新视频时，优先加入最近操作且有空位的可见视频墙。现有墙都满时自动新建一面。单路控制栏也可用 ↗ 切换为单独的无边框播放窗口。
4. 视频墙工具栏点 **全屏 (F11)**，在视频墙所在的屏幕上全屏显示，墙体工具栏与各路应用控制栏默认隐藏。鼠标移到某一路会显示它的控制栏，移出 1 秒后隐藏。控制栏浮在画面上方，画面保持原尺寸。按 **Esc** 或 **F11** 退出。文件窗口继续独立运行。
5. 关闭视频墙窗口会结束墙内所有播放页面。单路的关闭按钮结束对应页面。拖走最后一路后，额外创建的墙会关闭。退出浏览器窗口会关闭本次所有播放窗口。

## 窗口位置和大小

移动窗口或调整大小后会自动保存。重新启动时，浏览器恢复上次的位置和大小。视频墙再次打开时恢复上次的位置和大小；如果上次在全屏，加入第一路视频后恢复全屏。独立播放窗再次弹出时会按窗口顺序使用保存的大小和位置。显示器断开后，应用会把原本位于其上的窗口移到可见的屏幕。

布局文件位于 %LOCALAPPDATA%\115VideoWall\window-layout.json。

## 115 自动登录

1. 打开浏览器顶部的齿轮，进入「设置 → 115 账号与自动登录」，在应用里输入账号和密码。
2. 阅读 115 登录页中的协议与隐私政策后，确认允许自动勾选「我已阅读并同意」，点击「保存并启用」。
3. 之后打开程序时，如果 115 要求登录，程序会在 115 官方账号登录表单中填写并提交一次。出现验证码、滑块或其他验证时，在当前页面手动操作。
4. 可在同一入口更新或忘记账号和密码。忘记凭据会停用自动登录。

账号和密码由本机 Windows 凭据管理器保存。启动日志只记录流程结果。115 服务端仍可要求验证。

## 视频墙行列

在主窗口齿轮设置中取消勾选「视频墙自动排列」，设置每排视频数和竖向排数。设置应用到所有视频墙，会在下次启动时保留。缩小容量时，超出容量的视频会移到其他有空位的墙，必要时会新建视频墙。

## 老板键

打开「设置 → 快捷键」，勾选「启用老板键」，在输入框按下组合键。点「检测占用」可检查 Windows 是否允许注册。保存后全局生效。按下老板键会暂停并静音媒体、隐藏所有窗口，再按一次恢复窗口，播放需手动继续。

## 浏览其他网站与磁力链接

- 标签显示网站图标、完整标题的悬停提示和关闭热区。普通标签可以左右拖动排序，标签过多时可用滚轮或箭头浏览。115 固定在最左侧。
- 按住 Ctrl 单击普通网页链接，会在后台打开新标签，当前页继续显示。

- 浏览器顶部是一排图标。文件夹打开 115 文件，网格打开视频墙，文档打开日志。悬停可显示英文说明。
- 首标签固定用于 115，地址栏只读。用 + 或 Ctrl+T 新建普通标签。在普通标签的地址栏输入 HTTP(S) 网址或搜索词后，按 Enter 会在新标签打开并保留当前页面。Ctrl+W 关闭普通标签，Ctrl+Tab 切换标签。普通标签右侧有关闭 ×。按 Ctrl+Shift+T 或点撤销图标可恢复最近关闭的标签。点击网页打开的新窗口会进入普通标签或视频墙，取决于它是否为 115 播放页。
- 点击地址栏左侧的星标可展开或收起横排收藏栏。收藏栏位于地址栏下方、标签页上方，支持收藏此页、取消收藏、管理收藏和在新标签中打开收藏。Ctrl+D 收藏当前页。
- 点击时钟图标或按 Ctrl+H 打开可搜索的历史记录。书签、历史和最近关闭的标签保存在本机。
- 点击网页中的磁力或电驴文件链接，也可将链接粘贴到普通标签的地址栏后按 Enter。独立的后台 115 页面与前台共用登录状态，等待云下载模块准备好后提交，当前标签和前台 115 页面保持原样。结果显示 115 网页原有的提示。
- 修复了旧版限制网页跳转导致登录流程中断的问题。115 继续使用同一个本地 WebView2 配置，浏览器按站点设置保存有效的持久会话。

## 用户数据与日志

应用用 `%LOCALAPPDATA%\115VideoWall\webview-profile` 保存自己的浏览器登录状态。浏览器工具栏的文档图标会打开 `%LOCALAPPDATA%\115VideoWall\logs`。诊断日志记录打开结果、路数、网页全屏结果和错误码，省略页面标题、媒体 URL 和登录凭据。

## 构建和验证

在 Windows 上使用 .NET 8 SDK 构建。若要生成离线安装包，完成发布构建后，将微软 [WebView2 Fixed Version x64](https://developer.microsoft.com/microsoft-edge/webview2/#download) CAB 完整解开，把含有 `msedgewebview2.exe` 的目录内容复制到发布目录的 `WebView2Runtime`，然后用 NSIS 编译安装脚本。

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o .\dist\1.0.0
makensis /INPUTCHARSET UTF8 "/DPUBLISH_DIR=$PWD\dist\1.0.0" "/DSETUP_FILE=$PWD\dist\115VideoWall-Setup-1.0.0-x64.exe" "/DAPP_ICON=$PWD\assets\115VideoWall.ico" "$PWD\installer\115VideoWall.nsi"
```

调试构建可使用至少 12 秒的 H.264 MP4 跑本地集成测试。

```powershell
dotnet build
python smoke_test.py .\bin\Debug\net8.0-windows\115VideoWall.exe C:\path\sample.mp4
```

本地测试覆盖六路同时播放、单路暂停和跳转、弹窗与同页跳转、独立视频墙、无边框窗口、网页全屏自动启用和已开启状态、视频墙全屏时默认隐藏应用界面、单路悬浮控制栏和离开 1 秒后隐藏、退出全屏后恢复界面。115 实际使用的是官方播放器的网页全屏按钮。


联调还覆盖独立后台云下载、磁力和电驴链接、Ctrl 点击后台打开、标签拖动排序、横排收藏栏与重启后的持久浏览数据，以及关闭视频墙结束播放、老板键注册冲突和恢复窗口。
